\# RideMesh



RideMesh is a real-time mobility platform that connects customers with nearby captains.



\## V1 Scope



The first version supports bike rides only.



\### User Roles



\- Customer

\- Captain

\- Admin



\### Planned Technology Stack



\- Java 21

\- Spring Boot

\- PostgreSQL

\- Redis / Redis GEO

\- Apache Kafka

\- WebSocket

\- Spring Security

\- Docker

\- Kubernetes

\- GitHub Actions

\- AWS

\- Prometheus

\- Grafana

\- HTML

\- CSS

\- Bootstrap

\- Vanilla JavaScript

\- Leaflet



\## Architecture



RideMesh will follow a microservices architecture with a single responsive web application.



\## Development Workflow



\- Monorepo

\- Trunk-based development

\- `main` as the trunk branch

\- Short-lived feature branches

\- Pull requests

\- GitHub Actions CI/CD
